# 카카오톡 알림 붙이기 — 처음부터 끝까지

`digest` 결과를 카카오톡 **나와의 채팅**으로 받는 설정입니다. 약 10분.
한 번 하면 이후로는 `--notify kakao` 한 줄이면 됩니다.

이 문서는 **실제로 막혔던 지점을 그대로** 담았습니다. 한 번에 된 단계가 하나도 없었고, 순서대로
`KOE004 → KOE205 → KOE006 → KOE006(다른 칸) → 401`을 만났습니다. 각 에러가 어느 칸을 가리키는지
알면 10분, 모르면 한 시간짜리 설정입니다.

---

## 0. 먼저 알아야 할 것 — 이걸로 할 수 있는 일과 없는 일

| | |
|---|---|
| ✅ 되는 것 | 내 카카오톡 **나와의 채팅방**에 메시지 보내기 |
| ❌ 안 되는 것 | 남이 보낸 톡 **읽기** |
| ❌ 안 되는 것 | 친구·단톡방에 **보내기** |

카카오에는 개인 대화를 읽는 API가 **아예 없습니다.** 친구에게 보내는 건 심사받은 비즈니스 앱만
됩니다. 그래서 이 연동은 "나에게 한 줄 쓰기"가 전부이고, **그게 안전장치입니다** — 버그가 나도
남에게 닿지 않습니다. 이 저장소가 이걸 `channels/`가 아니라 `notify/`에 둔 이유입니다.

읽기까지 필요하면 화면 인식 경로여야 합니다([docs/kakaotalk.md](kakaotalk.md)).

---

## 1. 앱 만들기

https://developers.kakao.com/console/app → **애플리케이션 추가하기**

| 칸 | 넣을 값 | 비고 |
|---|---|---|
| 앱 아이콘 | 비워도 됨 | |
| **앱 이름** | `replydesk` | 동의 화면에 그대로 표시됨 |
| **회사명** | 개인 이름 또는 본인 브랜드 | 사업자 없어도 됨. 비즈 앱 전환 때만 대조함 |
| **카테고리** | 비즈니스 / 생산성 / 기타 | 심사와 무관 |
| 앱 대표 도메인 | 가진 도메인이 있으면 | 필수 아님 |

> 나에게 보내기는 **심사가 없습니다.** 앱은 계속 "개발 중" 상태로 두고 씁니다.

---

## 2. 웹 플랫폼 등록 — **포트를 넣으면 거부당합니다**

앱 설정 → **플랫폼** → **Web 플랫폼 등록**

```
❌ http://localhost:8123     →  "유효하지 않은 URL 입니다"
✅ https://sweet-butters.github.io
```

이 칸은 **진짜 도메인만** 받습니다. 포트도, localhost도 안 됩니다.
가진 도메인이 없으면 GitHub Pages 주소(`https<이름>.github.io`)면 충분합니다.

여기와 4단계의 Redirect URI는 **서로 다른 칸이고 값도 다릅니다.** 헷갈리는 1순위 지점입니다.

플랫폼 등록을 건너뛰면 나중에 `KOE004`가 납니다.

---

## 3. 카카오 로그인 켜기

제품 설정 → **카카오 로그인** → 페이지 맨 위 **활성화 설정 = ON**

켜지 않으면 `KOE004`가 납니다.

---

## 4. Redirect URI 등록 — **카카오 로그인 아래가 아닙니다**

여기가 이 문서에서 제일 중요한 칸입니다. 콘솔 버전에 따라 **위치가 다릅니다.**

**현재 콘솔(2026-09 기준)**

```
앱 설정 → 플랫폼 키 → REST API 키 줄의 [더보기] → Redirect URI 등록
```

앱 키를 복사하던 바로 그 화면입니다. Redirect URI가 **REST API 키에 딸려 있습니다.**

> **그 화면에는 비슷한 칸이 두 개 있습니다.** 이름이 거의 같아서 틀린 쪽에 넣기 쉽습니다.
>
> ```
> 리다이렉트 URI           ← 여기. 인가 코드가 돌아오는 주소
> 로그아웃 리다이렉트 URI   ← 아님. 로그아웃 후 이동할 주소
> ```
>
> 로그아웃 쪽에 등록하면 저장은 잘 되고, 인증할 때만 `KOE006`이 납니다. 설정은 분명히 했는데
> 같은 에러가 반복되면 **어느 칸에 넣었는지** 먼저 보세요. 칸 설명에 "[카카오계정과 함께
> 로그아웃]"이 적혀 있으면 틀린 칸입니다.

**예전 콘솔**

```
제품 설정 → 카카오 로그인 → (활성화 ON 후) 페이지 아래 Redirect URI
```

카카오 로그인 페이지만 뒤지다 못 찾는 경우가 많습니다. `KOE006`이 나면 에러 화면이 **그 콘솔이
쓰는 정확한 경로를 알려주므로** 그대로 따라가면 됩니다.

넣을 값:

```
http://localhost:8123/oauth
```

2단계 웹 도메인 칸과 비교해 보세요. 도메인 칸은 경로 없이 도메인만, 이 칸은 **경로(`/oauth`)까지
전부**입니다. `8123`은 이 저장소가 쓰는 포트입니다(`replydesk/notify/kakao.py`의 `PORT`).

---

## 5. 동의항목 켜기

제품 설정 → 카카오 로그인 → **동의항목** (왼쪽 하위 메뉴, 별도 페이지)

**"카카오톡 메시지 전송"(`talk_message`)** → 사용 설정 **ON**. 선택 동의로 둬도 됩니다.

안 켜면 동의 화면에서 `KOE205`가 납니다.

---

## 6. 키 저장 — **클라이언트 시크릿도 함께 확인**

앱 설정 → **앱 키** → **REST API 키**, 그리고 앱 설정 → **보안** → **클라이언트 시크릿**.

시크릿은 기본으로 **활성화**돼 있을 수 있습니다. 그 상태면 토큰 요청에 시크릿이 함께 가야 하고,
빠지면 동의를 정상적으로 마쳐도 **토큰 발급에서 401**이 납니다. 동의 화면까지 다 통과한 뒤라
"설정이 다 맞는데 왜?"로 보이는 게 이 단계의 함정입니다.

```bash
mkdir -p keys
echo -n "REST_API_키"      > keys/kakao_rest_api_key.txt
echo -n "클라이언트_시크릿"  > keys/kakao_client_secret.txt   # 활성화돼 있을 때만
git check-ignore -v keys/kakao_rest_api_key.txt      # .gitignore:6:keys/ 가 나와야 정상
```

시크릿을 안 쓰려면 **보안 → 클라이언트 시크릿 → 사용 안 함**으로 바꿔도 됩니다. 개인용이면
어느 쪽이든 동작합니다.

> 보안 화면에는 코드가 **두 개**입니다. **카카오 로그인** 쪽이 토큰 발급에 쓰는 것이고,
> **비즈니스 인증** 쪽은 우리가 쓰지 않습니다.

`keys/`는 `.gitignore`에 있습니다. **커밋되는지 위 명령으로 반드시 확인하세요.**

---

## 7. 연결

```bash
export KAKAO_REST_API_KEY_FILE="$PWD/keys/kakao_rest_api_key.txt"   # Windows: set 또는 $env:
export KAKAO_CLIENT_SECRET_FILE="$PWD/keys/kakao_client_secret.txt" # 시크릿이 활성화된 경우만
python -m replydesk.notify.kakao
```

브라우저가 열리고 동의 화면이 뜹니다. 동의하면 `http://localhost:8123/oauth`로 돌아오면서
"동의가 끝났습니다"가 보이고, 토큰이 `~/.replydesk/kakao_token.json`에 저장됩니다.

브라우저가 안 열리면 `--no-browser`를 붙이고 출력된 주소를 직접 여세요.

**이 과정에서 비밀번호는 아무도 묻지 않고, 이 프로그램은 리다이렉트를 받기만 합니다.**
로그인과 동의는 브라우저에서 본인이 합니다.

---

## 8. 확인

```bash
python -m replydesk.notify.kakao --test
```

폰의 나와의 채팅방에 한 줄이 뜨면 끝입니다.

```bash
python -m replydesk digest --channel gmail --account work,personal --notify kakao
```

## 막혔을 때

| 증상 | 원인 | 고치는 곳 |
|---|---|---|
| `KOE004` 앱 관리자 설정 오류 | 카카오 로그인이 OFF, 또는 플랫폼 미등록 | 3단계 → 2단계 |
| `KOE006` 등록되지 않은 Redirect URI | ① 위치를 못 찾음 ② **"로그아웃 리다이렉트 URI" 칸에 넣음** ③ 주소 불일치 | 4단계. 현재 콘솔은 [플랫폼 키] > REST API 키 > 더보기. **"로그아웃"이 안 붙은 칸**인지 확인하고, `http`/포트/`/oauth`를 글자 단위로 대조 |
| `KOE205` 동의항목 오류 | `talk_message` 미설정 | 5단계 |
| 웹 도메인 "유효하지 않은 URL" | 포트나 localhost를 넣음 | 2단계 — 진짜 도메인을 넣으세요 |
| Redirect URI 칸이 안 보임 | 카카오 로그인 페이지에서 찾고 있음 | 4단계 — 현재 콘솔은 [플랫폼 키] > REST API 키 > 더보기 |
| `카카오 연결이 없습니다` | 토큰 파일 없음 | 7단계를 먼저 |
| **토큰 발급에서 401** (동의는 성공했는데) | 클라이언트 시크릿이 활성화인데 안 보냄 | 6단계 — 시크릿을 넣거나 '사용 안 함'으로 |
| 전송 시 401 | 토큰 만료 | 자동 갱신됩니다. 그래도 나면 7단계를 다시 |
| `동의를 받지 못했습니다` | 동의 화면에서 체크박스를 안 켬 | `talk_message`는 선택 동의라 기본이 꺼져 있습니다 |

---

## 다른 컴퓨터에서 할 때

토큰은 **기기마다 새로 받습니다**(Gmail과 같은 규칙). 앱 설정은 그대로 두고 6~7단계만 다시 하면
됩니다. 토큰 파일은 옮기지 마세요.
